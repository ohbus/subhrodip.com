# Proposal

## Tracking issue

Tracking issue: #22

## Why

The search-style portfolio has no image-focused route for project screenshots or certificates.

## What Changes

Add an `/images` lazy route with a responsive masonry-style grid, accessible image metadata, and production asset loading checks.

## Capabilities

### New Capabilities

- `image-search-route`: responsive image search presentation for local portfolio assets.

### Modified Capabilities

None.

## Impact

Changes touch routes, a new standalone feature component, localized labels, and public assets. Existing pages and base routing must remain unchanged.
